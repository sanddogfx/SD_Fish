# SD_Fish

Android-приложение для рыбаков.

## Что умеет сейчас (шаг 1)

- Записать улов: место по GPS (можно поправить на карте), дата и время, вид рыбы, вес, длина, фото, заметка.
- Список всех уловов.
- Карта уловов (OpenStreetMap): нажми на метку, чтобы увидеть улов, ещё раз — чтобы открыть его.
- Язык: русский, польский или английский. По умолчанию как в телефоне, меняется в настройках (шестерёнка).
- Всё хранится на телефоне, без регистрации; записи работают без интернета.

## Как установить на телефон

1. Открой на телефоне страницу [Releases](../../releases/latest) этого репозитория (нужно войти в GitHub).
2. Скачай файл `SD_Fish-0.1.N.apk`.
3. Открой его. Android попросит разрешить установку из этого источника — разреши.
4. Дальше обновляться можно прямо из приложения: при запуске оно само проверяет новую версию и предлагает «Обновить» (в первый раз Android попросит разрешить SD_Fish установку приложений). Сохранённые уловы не пропадают.

Обновление из приложения работает, только если репозиторий публичный: приложение читает страницу Releases без входа в GitHub.

Каждое изменение в ветке `main` автоматически собирает новую версию (GitHub Actions → «Build APK»).
